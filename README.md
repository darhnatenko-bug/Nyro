# Nyro

Мобільний застосунок для пошуку та оплати паркомісць у Львові, розроблений у партнерстві з Львівавтодор.

## Про застосунок

Nyro допомагає водіям швидко знайти вільне паркомісце поруч, дізнатись тариф і сплатити прямо зі смартфону — без касирів і паркоматів.

## Стек технологій

- **Mapbox GL JS** — інтерактивна карта з реальними парковками Львова
- **Stripe** — онлайн-оплата паркування
- **PWA** — застосунок встановлюється на головний екран без App Store
- **Vanilla JS / HTML / CSS** — без фреймворків

## Запуск

```bash
git clone https://github.com/your-org/nyro.git
cd nyro
# Створи .env з API ключами (див. .env.example)
# Відкрий index.html у браузері або запусти через Live Server
```
